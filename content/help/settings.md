# Brand settings

Open **Settings** at the bottom of the sidebar. The tabs are:

| Tab | What's there |
|---|---|
| **Brand workspace** | Name, connected Figma file, delete the brand. |
| **Plan & usage** | Your plan, files and designs used, the cap for extra designs, upgrade or manage billing, and the **Library** section (how much is organised and searchable). See [Plans](plans) and [Billing](billing). |
| **Team** | People and roles. See [Team, invites and roles](team-and-roles). |
| **Activity** | Enterprise only, admins and owners. See [Activity log](activity-log). |
| **Integrations** | Admins and owners: keys that let other tools show the Mise picker. See [Use Mise inside other tools](integrations). |
| **Claude** | Your connector link and setup. See [Connect Claude](claude-connector). |
| **Help** | Ask Mise a question, or browse this help centre. Also opens from **Help** in the sidebar. |

## Brand workspace
- **Workspace name**: up to 60 characters.
- **Connected Figma file**: paste the link to this brand's Figma design-system or email file (Share → Copy link in Figma). Claude uses it by default. If the link isn't a Figma file you'll see "That doesn’t look like a Figma file link…".
- **Save**: owners and admins only.

## Delete this brand
Owners only. Removes the brand for everyone: every file and version, folders, collections, the brand kit, portals, share links and team access. If the brand is on Pro, its subscription stops today. Type the brand's name to confirm. This can't be undone.

If the subscription can't be stopped you'll see "Couldn’t stop this brand’s subscription, so it wasn’t deleted. Try again." Nothing is deleted in that case.
