# No longer available: archive, licence expiry and obsolete files

Files that shouldn't be used any more stay in Mise for the record, clearly marked, so nobody uses them by mistake.

| State | Meaning | Downloads by your team |
|---|---|---|
| **Archived** | Retired by hand, for example an old campaign. | Allowed |
| **Licence expired** | The licence or usage rights have run out. | Blocked |
| **Obsolete** | Superseded, for example an old logo, with a link to the replacement. | Allowed |

Files in any of these states are hidden from the library (except under **No longer available**), and **aren't** offered in Create, share links, portals or to Claude.

## Archive a file (every plan)
Open the file → **Availability** → **Archive**. Add a reason if you like ("Old campaign"). Find it later under the **No longer available** filter on Assets.

## Set a licence end date (Pro)
For stock or licensed photos: open the file → **Availability** → **Licence ends** → pick the date.
- Files whose licence ends within 30 days show **Licence ends {date}** on their tile.
- **On that date** the file becomes *Licence expired* automatically: it can't be downloaded, shared or used in new work, and share links and portals stop showing it.
- A date in the past expires the file straight away.

## Mark a file obsolete (Pro)
Open the file → **Availability** → **Mark obsolete…** → add a reason ("Replaced by the 2026 logo") and pick **Use instead**, the file people should use now. Your team sees **Use instead** on the old file, and Claude uses the replacement instead.

## Bring a file back
Open it (Assets → filter **No longer available**) → **Make available**. For an expired file, click **Renew** and set the new licence end date.

## What the people you share with see
If a share link includes files that are no longer available, they're left out and the page says "{n} files in this link are no longer available. Ask {brand} for their replacements."

## Products that leave your feed
When a synced product leaves your Shopify store or feed, it's marked unavailable with the reason "No longer in the product feed", and made available again if it comes back. See [Products](products).
