# Limits and fair use

## Files
| | Limit |
|---|---|
| Image upload | 50 MB |
| Video upload | 1 GB |
| Import from Drive, Dropbox, Box or a link | 100 MB per file (images 50 MB) |
| Product photos from a feed | 25 MB each |
| Files on Free | 50 (email blocks and product records without photos don't count) |
| Files on Pro and Enterprise | No limit |
| Products per feed sync | 10,000 |
| Files per share link | 500 |

## Designs, photos and video each month (per brand)
| | Included | After that |
|---|---|---|
| Free | One Create run | Upgrade |
| Pro | 200 designs | 60¢ each up to your cap |
| Enterprise | 1,000 designs | As agreed |

See [What counts as a design](plans#what-counts-as-a-design).

Photos: up to 4 per request. Video: 4, 6 or 8 seconds, 9:16 or 16:9.

## Fair use (per brand, per month)
These are generous ceilings that a real brand never meets. They only stop runaway imports or abuse.
| | Ceiling |
|---|---|
| Files organised | 20,000 |
| Plain-English searches | 10,000 |
| Brand kits built from a website | 30 |

If you reach one, Mise tells you. Search still works on words and meaning. Send a message through **Feedback** if you need more.

## Text and settings
| | Limit |
|---|---|
| File name | 120 characters |
| Description | 400 characters |
| Alt text | 300 characters |
| Tags per file | 30 |
| Folder name | 60 characters |
| Brand name | 60 characters |
| Team image sizes | 30 |
| Share link or portal passcode | At least 4 characters |
| Portal invite list | 500 emails or domains |
| Brand kit imagery rules | 8 do's and 8 don'ts, 6 reference images |
