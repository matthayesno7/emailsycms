# Versions and undo

Nothing in Mise is overwritten. When a file is edited (by you, a teammate, or Claude), the previous version is kept.

## See the history
Open the file. **Versions** in the side panel lists the current version and earlier ones, with what changed, the size and the date. **Show all versions** shows the full list.

## Restore an earlier version
Click **Restore** next to it. "Back to version {n}. The version you replaced is kept." Restoring is itself a new version, so you can always go back again.

What stays the same across versions: tags, folder, product link, smart collections and share links. A share link always shows the current version.

Restoring is part of editing, so it's on Pro.

## Deleting
**Delete asset** removes the file and every version, for everyone. It can't be undone.
